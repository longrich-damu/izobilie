# Моё изобилие

Готовый сайт для GitHub Pages. Сиреневый и малиновый, отдельное «Послание дня», покупки с фотографиями и личная история на 45 игровых дней. Сборка и установка зависимостей для публикации не нужны.

## Как разместить на GitHub

1. Распакуй архив `moe-izobilie-github.zip` на компьютере.
2. Создай на GitHub новый репозиторий, например `moe-izobilie`. Для GitHub Free выбери **Public**.
3. Открой репозиторий и выбери **Add file → Upload files**. В пустом репозитории можно нажать **uploading an existing file**.
4. Загрузи содержимое распакованной папки. Файл `index.html` должен оказаться прямо в корне репозитория, рядом с `app.js`, `core.js`, `messages.js` и `styles.css`. Не загружай ZIP вместо распакованных файлов.
5. Сохрани загрузку кнопкой **Commit changes**.
6. Открой **Settings → Pages**. В разделе **Build and deployment** выбери **Source: Deploy from a branch**.
7. Выбери ветку **main**, папку **/(root)** и нажми **Save**.
8. Дождись публикации: адрес появится на этой же странице. Открой его и начни свою игру.

Пример адреса: `https://твой-логин.github.io/moe-izobilie/`.

Официальная инструкция GitHub: [публикация из ветки репозитория](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Как устроена игра

- В день 1 начисляется 5 000 ₸, в день 2 — 10 000 ₸; каждый новый игровой день добавляет 5 000 ₸.
- Добавь покупки, стоимость, заметки и фотографии по желанию. Сайт считает остаток сам.
- Когда остаток равен нулю, нажми **Завершить день**.
- Следующий день открывается на следующую календарную дату по времени устройства.
- Если день пропущен или заполнен частично, он остаётся текущим. Дополнительные деньги за пропуски не начисляются.
- Игра длится **45 завершённых игровых дней**, поэтому с пропусками займёт больше 45 календарных дней.
- Все деньги и покупки воображаемые. На 45-й день начисляется 225 000 ₸, за все дни — 5 175 000 ₸.

На главной показана актуальная дата устройства. В истории сохраняются номер игрового дня, дата начала и завершения, фотографии и записи.

## Разделы

- **Сегодня:** дата, номер дня, послание, сумма, остаток и покупки.
- **История:** 45 дней, фотографии и записи. Будущие дни закрыты.
- **Итоги:** начисления, записанные расходы, число покупок, завершённые дни и итоги по игровым неделям.
- **Настройки:** имя, правила, скачивание и восстановление резервной копии.

В завершённых днях можно менять названия, заметки и фотографии. Стоимость и состав покупок сохраняются, чтобы завершённый день оставался распределённым до нуля.

## Личный дневник каждого участника

Можно дать партнёрам одну ссылку: у каждого на своём устройстве будет собственный дневник. При первом входе каждый вводит имя и выбирает дату начала.

Можно также сделать отдельные копии сайта в разных репозиториях. Данные копий разделены по пути сайта.

Это версия **без учётных записей и облачного хранения**. Записи хранятся в IndexedDB в браузере; приложение не отправляет покупки и фотографии на сервер. Два человека в одном браузере по одной ссылке будут видеть один дневник. Для раздельных дневников на одном компьютере используйте разные профили браузера или отдельные копии сайта.

Сайт доступен по публичной ссылке GitHub Pages. Публичность сайта не публикует локальные записи, но парольного доступа к дневнику на устройстве нет.

## Резервные копии и фотографии

В **Настройках** нажми **Скачать резервную копию**. Получится JSON-файл со всеми покупками, игровыми днями и фотографиями. Список посланий находится в `messages.js`; при восстановлении сайта они снова показываются по номерам игровых дней.

Чтобы продолжить на другом устройстве, открой на нём сайт и выбери **Восстановить из файла**. Восстановление заменяет текущий дневник; автоматического объединения между устройствами нет.

Очистка данных браузера, приватный режим и смена адреса сайта могут сделать прежний дневник недоступным. Скачивай копию после важных записей. Резервные копии содержат личные записи: **не загружай их в репозиторий GitHub**.

Фотографии до 20 МБ автоматически уменьшаются до 1400 пикселей по длинной стороне и сохраняются в JPEG, чтобы занимать меньше места. Можно загрузить JPG, PNG, WebP, AVIF или GIF; для GIF сохраняется один кадр. Качество рассчитано на просмотр в дневнике, а не на хранение оригиналов.

## Состав файлов

```text
index.html       Страница и формы
styles.css       Утверждённое оформление
app.js           Интерфейс, фотографии, IndexedDB и резервные копии
core.js          Деньги, переходы между днями и проверка копий
messages.js      45 посланий
favicon.svg      Значок сайта
.nojekyll        Публикация статических файлов без Jekyll
package.json     Только команда проверки; сборка не нужна
tests/           Проверки логики
QA.md            Что проверено и что осталось проверить в браузере
```

Для публикации достаточно загрузить всё содержимое архива. Приложению не нужны API-ключи, платный сервер или Google Календарь. Дата берётся с устройства.

## Проверки для разработчика

Нужен Node.js с поддержкой встроенного `node:test`:

```sh
npm test
```

Для локального просмотра запусти HTTP-сервер в папке сайта, например `python -m http.server 8000`, и открой `http://localhost:8000`. Модули JavaScript рассчитаны на HTTP(S); открытие `index.html` двойным щелчком через `file://` не предназначено для работы дневника.
